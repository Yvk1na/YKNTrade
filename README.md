# YknTrade

适用于 Paper 1.21.10 及以上、使用 Java 25 编译的双人交易插件。需要安装 Vault，以及一个已向 Vault 注册经济服务的经济插件。

## 功能

- 玩家蹲下并右键另一名玩家发起申请，对方可直接点击聊天消息接受。
- Citizens 创建的 NPC 会被自动识别，不能成为交易申请目标。
- 申请有效期固定为一分钟；期间发起者不能再次申请。对方蹲下右键发起者也会直接接受，超时后双方都会收到提示。
- 45 格双栏交易界面：左侧是自己的可编辑报价，右侧是对方的只读预览。
- 支持从玩家背包 Shift 点击物品，自动合并并放入自己左侧的交易报价槽位。
- 支持物品与 Vault 余额同时交换，金额可使用 `K`、`M`、`B`、`T` 后缀。
- 金额达到 100M 时使用钻石块显示；达到 1B 后每个钻石块代表 1B，余数使用金块显示。
- 任一方改变物品或金额后，双方确认状态都会清除，并进入 3 秒 `Waiting`。
- 双方都确认后才会扣款和交换物品；余额不足或 Vault 拒绝交易时不会交付物品。
- 关闭界面、离线或插件停用时自动取消，并退回已放入的物品。背包已满时物品会掉落在玩家脚下。
- 交易成功或交易会话取消后，双方的交易申请冷却都会立即重置。
- 管理员使用 `/trade admin` 打开可翻页的交易记录箱子；每页显示 45 笔，每张纸包含北京时间、双方物品和余额报价。
- 交易记录仅保留最近 7 天；插件启动、查看、新增记录以及运行期间每分钟都会自动清理过期数据。
- 玩家主动丢出的物品以及玩家破坏方块产生的掉落物，仅原玩家可以拾取；所有者标记只写在地面物品实体上，本人完整拾取时会清除，不会写入背包物品组件或影响堆叠。

## 安装

1. 服务端使用 Paper 1.21.10 或更高版本，并以 Java 25 启动。
2. 安装 `Vault` 和一个兼容 Vault 的经济插件。
3. 将 `build/libs/ykntrade-1.4.5.jar` 放入服务端的 `plugins` 目录。
4. 重启服务端。

余额输入使用 Paper 1.21.10 的原生虚拟告示牌界面。虚拟告示牌只发送给当前玩家，不会修改世界方块，也无需 ProtocolLib。

## 构建

PowerShell：

```powershell
$env:JAVA_HOME = 'C:\java\25'
.\gradlew.bat clean test build
```

配置项位于 `plugins/YknTrade/config.yml`：报价变化后的确认等待时间默认 3 秒。申请接收/发起、接受按钮、交易成功、交易取消与请求过期文案均可在 `messages` 中修改，并支持 `&` 颜色代码及配置文件注明的占位符。交易申请有效期固定为一分钟，交易记录持久化在 `plugins/YknTrade/history.yml` 并仅保留最近 7 天。
